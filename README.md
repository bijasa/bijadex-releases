# Bijadex releases

Installers for **Bijadex**, the point-of-sale and inventory app for retail shops by [Bijasa](https://bijasa.com).

Download the latest version from **[Releases](https://github.com/bijasa/bijadex-releases/releases/latest)**:

- **Windows:** `Bijadex-<version>-win-x64.exe`
- **macOS:** `Bijadex-<version>-mac-arm64.dmg` (Apple silicon) or `-mac-x64.dmg` (Intel)

Each file has a `.sha256` checksum. Installed Windows apps update themselves from this page.

This repository holds installers only. Source code is private. Support: hello@bijasa.com
